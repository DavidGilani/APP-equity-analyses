About this dashboard

Results come from equity_gaps_all_levels_long.csv, produced by app_equity_gaps.R from the OfS individualised student data. The population is full-time, UK-domiciled first degree students registered at Middlesex. Only the four academic faculties are shown.

Equity gap

The comparator group's rate minus the target group's rate, in percentage points. A positive gap means the target group does worse. BTEC entrants are compared with A-level entrants for continuation, completion and attainment, and with all other qualifications for progression.

Status

  • Target met: the latest gap is at or below the 2028-29 target.
  • On track: the latest gap is at or below the 2027-28 milestone.
  • Behind milestone: the latest gap is above the 2027-28 milestone.
  • Small numbers: either group has fewer than 10 students in the latest year.

Is the difference significant?

Each gap has a 95% margin of error based on the number of students in each group. If the whole range sits above the milestone, the area is significantly behind. If it sits below, it is significantly ahead. Otherwise the difference could be chance.

Tableau calculation: 1.96 * SQRT(pT*(1-pT)/nT + pC*(1-pC)/nC) * 100, where p is each group's rate and n its headcount. The R export includes this as margin_pp, with significance alongside it.

Direction of travel

Compares the latest gap with the four-year pooled baseline. A change of 1 percentage point or more is shown as narrowed or widened.

Progress map

Across: how far the latest gap is below the milestone or target, so right is better. Up: how far the gap has narrowed since the baseline, so up is better. Bubble area shows the number of students in the target group. Colour shows whether the difference from the milestone or target is significant.
