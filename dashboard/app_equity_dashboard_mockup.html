About this dashboard

This mockup uses invented figures for 48 programmes. The structure, definitions and calculations match the R export in equity_gaps_all_levels_long.csv, so the same layout can be rebuilt in Tableau from that file.

Equity gap

The comparator group's rate minus the target group's rate, in percentage points. A positive gap means the target group does worse. BTEC entrants are compared with A-level entrants for continuation, completion and attainment, and with all other qualifications for progression.

Status

  • Target met: the latest gap is at or below the 2028-29 target.
  • On track: the latest gap is at or below the 2027-28 milestone.
  • Behind milestone: the latest gap is above the 2027-28 milestone.
  • Small numbers: either group has fewer than 10 students in the latest year.

Is the difference significant?

Each latest gap has a 95% margin of error based on the number of students in each group. If the whole range sits above the milestone, the area is significantly behind. If it sits below, it is significantly ahead. Otherwise the difference from the milestone could be chance.

Tableau calculation: 1.96 * SQRT(pT*(1-pT)/nT + pC*(1-pC)/nC) * 100, where p is each group's rate and n its headcount.

Direction of travel

Compares the latest gap with the four-year pooled baseline. A change of 1 percentage point or more is shown as narrowed or widened. The sparkline shows all seven years, with the milestone for each of the last three marked in black.
