# Working in this repository

- Commit and push directly to `main`. Do not create branches or pull requests. If a session starts on another branch, move the work onto `main` and delete the other branch.
- The repository holds code and documentation only. Never commit student data, tracker data, meeting notes, transcripts, completed templates or snapshots.
- Work on the APP tracking and reporting tool lives in `APP reporting tool/`. Start with `APP reporting tool/README.md`.
- Written text follows David's tone of voice: sentence case headings, no em-dashes.
